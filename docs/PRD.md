# PRD — 몽골 선교 2026

**Product Requirements Document**  
버전: 1.0 | 작성일: 2026-06-22

---

## 1. 제품 개요

**몽골 선교 2026**은 GBC(Grace Bible Church) 단기선교팀의 몽골 선교 활동(2026년 6월 28일 ~ 7월 4일, 7박)을 지원하기 위한 **모바일 전용 웹앱**이다.

팀원들이 현장에서 필요한 모든 정보(일정, 가이드, 큐시트, 가사 등)를 한 곳에서 확인하고, 외부 후원자들이 기도편지를 열람할 수 있도록 한다. 별도 앱 설치 없이 링크 하나로 접근 가능하며, 백엔드 서버 없이 정적 데이터 기반으로 운영된다.

---

## 2. 목표

| 목표 | 측정 기준 |
|------|----------|
| 팀원이 현장에서 필요한 정보를 3초 이내에 찾을 수 있다 | 홈 빠른 진입 카드 → 목표 페이지 2탭 이내 도달 |
| 후원자가 기도편지를 앱 설치 없이 열람할 수 있다 | 링크 공유 → 기도편지 전체화면 뷰어 접근 |
| iOS Safari / 카카오톡 인앱 브라우저에서 정상 동작한다 | 크리티컬 UI 오류 0건 |
| 선교 기간(7일) 동안 서버 장애 없이 운영된다 | Vercel 정적 배포로 다운타임 0 |

## 4. 기능 요구사항

### 4.1 홈 (`/`)

- D-day 카운트다운 — 출발일(2026-06-28) 기준, 실시간 갱신
- 선교 말씀 표시 (이사야 52:7)
- 7개 빠른 진입 카드: 기도편지, 가이드북, 매일 QT, 전도 구문집, 공연 큐시트, 합창곡, 공동 기도제목
- 각 카드에 대상 역할 배지 표시 (전체 / 매일 / 전도팀 / 스태프 등)

### 4.2 기도편지 (`/prayer-letters`)

- 기도편지 목록 — 2열 그리드, 썸네일 이미지
- 이미지 탭 시 전체화면 뷰어 오픈 (모달)
- 개별 상세 페이지 (`/prayer-letters/[id]`) — OG 메타태그 포함, 카카오 공유 가능
- 정적 배열(`data/prayer-letters.ts`) 기반 수동 관리

### 4.3 가이드북 (`/guide`)

- **날씨** — 몽골 여름 날씨 특성 안내 (일교차, 자외선, 강수)
- **준비물 체크리스트** — 5개 카테고리, 체크 상태 로컬 기기에 저장
  - 서류/기본, 의류/신발, 자외선/먼지 차단, 의약품/위생, 식품/생활용품
- **안전수칙** — 교통 안전 등 현지 주의사항
- **긴급 연락처** — 아코디언 섹션, 전화번호 즉시 통화 연결

### 4.4 매일 QT (`/qt`)

- 베드로전서 기반 7일 묵상 콘텐츠
- 날짜별 탭 전환 (Day 1 ~ Day 7)
- 각 날짜마다 본문 말씀, 묵상 포인트, 디브리핑 섹션 제공
- 디브리핑: 은혜/개선 입력 및 저장

### 4.5 전도 구문집 (`/phrasebook`)

- 한국어 → 몽골어 표현 제공 (발음 포함)
- 섹션별 아코디언 (인사, 전도, 일상 등)
- 각 구문 스피커 버튼: 오디오 파일 재생 또는 TTS fallback
- 재생 중 단어별 하이라이팅

### 4.6 공연 큐시트 (`/cuesheet`)

- 3개 공연 날짜 탭 (6/29, 7/1, 7/2)
- 공연 진행 순서표: 순번, 구분, 내용, 담당자, 시간
- 기술 정보 태그: 무대, 마이크, 오디오, 스크린, 조명
- 행 타입별 색상 구분 (리허설, 셋업, 클린업, 사회, 공연)

### 4.7 합창곡 (`/song`)

- 합창 가사 전문 (파트별: 솔로 1~6, 남/여, 다같이)
- 한·몽 이중 언어 가사 (한국어 / 몽골어 / 발음)

### 4.8 공동 기도제목 (`/group-prayer`)

- 10가지 공동 기도제목 목록
- 후원 계좌 정보 표시 + 계좌번호 클립보드 복사

## 5. 비기능 요구사항

### 5.1 성능

- 첫 로드 LCP 3초 이내 (4G 기준)
- 이미지: 기도편지 썸네일 lazy loading 적용

### 5.2 호환성

| 브라우저 | 지원 수준 |
|---------|----------|
| iOS Safari 15+ | 필수 (Primary) |
| Android Chrome 90+ | 필수 (Primary) |
| 카카오톡 인앱 브라우저 | 필수 |
| 삼성 인터넷 | 권장 |

- 노치/홈바 safe-area 대응 필수
- `backdropFilter` + `WebkitBackdropFilter` 쌍으로 작성 (iOS 15 이하)

### 5.3 접근성

- 터치 타겟 최소 44×44px
- 충분한 색상 대비 (WCAG AA 기준)
- 버튼에 aria-label 제공

### 5.4 보안 / 프라이버시

- 백엔드 없음 — 사용자 데이터 서버 전송 없음
- 체크리스트, QT 디브리핑: 로컬 스토리지 저장 (기기 한정)
- `localStorage` 접근 시 try-catch 필수 (iOS Safari Private Mode 대응)

## 8. UI 패턴 원칙

- **모바일 전용** — 375px 기준, 데스크탑 대응 불필요
- **Glass Morphism** — `rgba(255,255,255,0.72)` + `backdrop-filter: blur(24px)` 일관 적용
- **색상 팔레트** — 그린(`#16A34A`) + 베이지(`#FAFAF5`) 기조
- **하단 여백** — 전 페이지 `pb-20` (BottomNav 높이 확보)
- **뒤로가기** — `document.referrer` same-origin 확인 후 `router.back()` 또는 `router.replace()`
